# Deploy su Vercel

## 🚀 Deploy rapido

1. **Installa Vercel CLI:**
```bash
npm install -g vercel
```

2. **Effettua il login:**
```bash
vercel login
```

3. **Deploy dal progetto:**
```bash
cd /Users/riccardomoricone/telegram-bot-pc-components
vercel
```

4. **Rispondi alle domande:**
- `Set up and deploy`? <b>Y</b>
- `Which scope`? <b>ComponentiPCconIA_bot</b> o il tuo account
- `Link to existing project`? <b>N</b>
- `What's your project's name?`: componenti-pc-windows
- `Where should the function reside?`: <b>Enter</b> (default)
- `Configure and optimize`? <b>N</b>
